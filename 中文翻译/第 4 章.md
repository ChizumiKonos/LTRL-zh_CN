## 词汇注释

➤ 名词 **causa, causae** *f.* 的一般含义是"理由"或"原因"，更具体的含义是法律上的"案件"。

➤ **sententia, sententiae** *f.* 源自动词 **sentiō**，指意见，既可以是私下持有的（想法、感受），也可以是公开表达的（投票、意见）。在前一种意义上，它可以指演讲或表达背后的含义。在后一种意义上，它可以指法庭的"判决"或"判刑"。它也可以指书面或口头的"句子"。

➤ **altum, altī** *n.* 是形容词 **altus, -a, -um** 的名词化形式，可以表示"深海"或"高处"。 

➤ **auxilium, auxiliī** *n.* 是一个**抽象名词**，即表示无法被感官感知的事物（如智慧、幸福、奴役）的名词。拉丁语中抽象名词的复数形式通常用于具体含义。因此，在军事语境中，**auxilium** 的复数形式——**auxilia, auxiliōrum** *n., pl.*——意为"辅助部队"，即盟军士兵组成的部队，而非公民兵。 

➤ **socius, sociī** *m.* 是形容词 **socius, -a, -um** 的名词化形式。它既用于个人语境（同志），也用于法律和政治语境（盟友）。它常指意大利境外与罗马结盟的城市或民族。

➤ **agō, agere, ēgī, āctus** 是一个泛指动作的动词，其具体含义取决于上下文和伴随该动词的特定直接宾语。它可以表示"驱赶"（牛、羊、战利品、战车、风）；"做"、"行动"、"管理"、"辩护"（法庭案件）；或"度过"、"进行"（时间、生活）。

➤ **canō, canere, cecinī, cantus** 是一个及物动词，因此带直接宾语。第三主要部分 **cecinī** 是重叠形式（参见 **dedī**）。

- **Poeta bellum canebat.**  诗人在歌唱战争。

在拉丁语中，这个动词的直接宾语总是宾格。

➤ 在 **capiō, capere, cēpī, captus** 的第三主要部分中，词根元音变为长音 **-ē**。元音的变化表示时态的变化。词根元音的变化对应意义的变化，这称为**元音交替**（ablaut）。这种现象在所有原始印欧语言中都很常见。参见英语 **sing, sang, sung, song**。

➤ **dīcō, dīcere, dīxī, dictus** 是一个表示*给予*、*展示*和*告诉*的动词，因此可以带直接宾语和间接宾语。

➤ **dūcō, dūcere, dūxī, ductus** 有一个具体含义“引导”和一个抽象含义“认为”。

➤ 在 **faciō, facere, fēcī, factus** 的第三主要部分中，词根元音表现出元音交替，变为 **-ē**（参见 **capiō**）。**faciō** 是一个及物动词，意为"制造"、"做"。"制造"包括创造、引起或表现某物的概念。"做"意为执行或实施一个行动、行为、罪行、命令等。在现在时系统的被动语态中，**faciō** 有不规则形式，由动词 **fīō** 构成（§126）。在学习这些形式之前，**faciō** 的动词形态总览应仅包括主动形式。

➤ **gerō, gerere, gessī, gestus** 有三种不同的含义：

1. "穿戴"或"携带"（装备、衣物）；
2. "具有"或"带有"，作为身体或心灵的永久或暂时特征（伤口、声誉、愤怒）；
3. "管理"、"进行"或"履行"（自己、事务、公职）。

这三种含义中的第一种仅见于诗歌。

➤ 在 **mittō, mittere, mīsī, missus** 的第三主要部分中，词根元音表现出元音交替，变为 **-ī**。**mittō** 在指明接受者时，通常与两种结构连用：**ad** + 宾格或指涉与格。  

- **Agricola ad fīlium pecūniam mittit.** 农民送钱给（他的）儿子。  
- **Agricola fīliō pecūniam mittit.** 农民送钱给（他的）儿子。  

当 **mittō** 与 **ad** + 宾格连用时，介词短语强调朝向某人或某物的运动。与指涉与格连用时，强调某物所要送到的人（即，农民送钱送给**儿子**）。

➤ **pōnō, pōnere, posuī, positus** 有两种不同的含义：1. "放置"、"安放"；2. "放下"、"放弃"、"搁置一旁"。比较下面的两个句子：

- **Incolae arma in oppidō pōnunt.** 居民们正在把武器放置在城里。
- **Incolae arma pōnunt.** 居民们正在放下武器。（停战/投降）

上下文通常能明确哪种含义是合适的。

➤ **audiō, audīre, audīvī, audītus** 是一个及物动词，不过也可以独立使用。当它带直接宾语时，可以翻译为"听到"或"听见"。当它独立使用时，可以翻译为"听着"或"听"。

- **Rēgīna incolās audit.** 女王听到/听见居民（的声音）。
- **Rēgīna audit.** 女王听（着）。

➤ 在 **sentiō, sentīre, sēnsī, sēnsus** 的第三主要部分中，词根元音表现出元音交替，变为 **-ē-**。第四主要部分中的 **-ē-** 在 **-ns-** 前是长音。**-ns-** 前的短元音总是变长（例如 **īnsula**）。**sentiō** 的基本含义是"通过感官之一感知"。因此，它有智力上的含义（感知、观察、注意）和更具体或情感上的含义（经历、感觉、遭受）。

➤ 在 **veniō, venīre, vēnī, ventum** 的第三主要部分中，词根元音表现出元音交替，变为 **-ē-**。**veniō** 是一个不及物动词。

➤ **clārus, -a, -um** 的基本含义是视觉上的"明亮"或"清晰"。在这个意义上，它通常描述诸如天空、颜色或闪电之类的事物。当描述更抽象的概念（计划、事务）时，它的含义引申为"明显的"或"清楚的"。当用于人时，它意为"著名的"或"杰出的"。

➤ **cupidus, -a, -um** 是一个常与宾语属格（§36）连用的形容词。

➤ 因为形容词 **paucī, paucae, pauca** 意为"少数的"，所以它只以复数形式出现，其词汇条目包括阳性、阴性和中性复数主格形式。词干是 **pauc-**。这个词常与部分属格（§34）一起出现。

➤ **per** 是一个介词，带宾格，表示"穿过"空间或时间的运动。它也可以翻译为"遍及"或"沿着"。**per** 也表达手段或媒介的概念（常与人称代词连用），有时可以翻译为"通过"、"借由"。

- **Per viās oppidī ambulābimus.** 我们将穿过镇上的街道。
- **Sententia populī per bonōs mōnstrātur.** 人民的意见正通过好人展示出来。
- **Oppidum per arma tenēbant.** 他们通过武力控制着城镇。

➤ **quidem** 是一个后置副词，通常强调（“确实”、“当然”）或限定（“至少”）紧接在它前面的词。

- **Pulchrum quidem est amāre.** 爱确实是美好的。（强调）
- **Mihi quidem malum est bellum.** 至少对我来说战争是坏事。（限定） 

**quidem** 也可以强调或限定整个句子。

➤ ➤ **equidem**（小品词 **e-** + **quidem**）是一个副词，通常与第一人称单数或复数动词连用。它用于强调关于自己的事情或肯定自己的观点。**equidem** 不是后置词。

- **Equidem prō patriā pugnābō.** 就我而言，我将为祖国而战。

➤ **nē … quidem** 翻译为"甚至不"，并包围被修饰的词或词组。

- **Rēgīna ne fīliō quidem aurum dat.** 女王甚至不给（她的）儿子金子。

## §30. 第三、第三 i-词干和第四变位法的现在时、未完成时和将来时主动态与被动态直陈式

第三变位法的动词特点是现在时词干末尾有一个短 **-e-**。例如：

**regō, regere, rēxī, rēctus** 统治  
现在时词干：**rege-**

第三变位法的一个子类（第三 i-词干变位法）的特点是第一主要部分 **-ō** 结尾前有一个 **-i-**。例如：

**cap*iō*, capere, cēpī, captus** 拿，捕获  
现在时词干：**cape-**

第四变位法的动词特点是现在时词干末尾有一个长 **-ī-**，且第一主要部分 **-ō** 结尾前有一个 **-i-**。例如：

**aud*iō*, aud*ī*re, audīvī, audītus** 听见，听  
现在时词干：**audī-**

为了构成第一和第二变位法动词的现在时、未完成时和将来时主动态与被动态直陈式，需将中缀、词尾或两者直接加到现在时词干上。相比之下，为了构成第三、第三 i-词干和第四变位法动词的现在时、未完成时和将来时主动态与被动态直陈式，**在添加中缀或词尾之前，必须对词干元音进行某些规律性的变化**。

### 第三、第三 i-词干和第四变位法的现在时主动态与被动态直陈式

构成第三、第三 i-词干和第四变位法的现在时主动态和被动态直陈式的步骤：

1. 取现在时词干
2. 如下所示改变词干元音：
	- 第三变位法：**-e- → -i-​**
	- 第三 i-词干变位法：**-e- → -i-​**
	- 第四变位法：**-ī-** 保持不变​
3. 在 *改变后的* 现在时词干上直接添加 *主动态* 或 *被动态人称词尾*（第一人称单数用 **-ō** 或 **-or**）

因此，例如 **regō, capiō** 和 **audiō** 的现在时主动态与被动态直陈式变位如下：

| 改变后的现在时词干： | regi-       |                     | capi-       |                     | audī- (no change) |                     |
| ---------- | ----------- | ------------------- | ----------- | ------------------- | ----------------- | ------------------- |
|            | *主动态*       | *被动态*               | *主动态*       | *被动态*               | *主动态*             | *被动态*               |
| *单数*       |             |                     |             |                     |                   |                     |
| 1          | **regō**    | **regor**           | **capiō**   | **capior**          | **audiō**         | **audior**          |
| 2          | **regis**   | **regeris/ regere** | **capis**   | **caperis/ capere** | **audīs**         | **audīris/ audīre** |
| 3          | **regit**   | **regitur**         | **capit**   | **capitur**         | **audit**         | **audītur**         |
| *复数*       |             |                     |             |                     |                   |                     |
| 1          | **regimus** | **regimur**         | **capimus** | **capimur**         | **audīmus**       | **audīmur**         |
| 2          | **regitis** | **regiminī**        | **capitis** | **capiminī**        | **audītis**       | **audīminī**        |
| 3          | **regunt**  | **reguntur**        | **capiunt** | **capiuntur**       | **audiunt**       | **audiuntur**       |

**注意**

1. 在所有第三变位法动词的第一人称单数中，改变后的现在时词干末尾的 **-i-** 与词尾 **-ō** 和 **-or** 缩合（例如，\*regiō > **regō**；\*region > **regor**）。第一人称单数主动态即是**第一主要部分**。
2. 在所有第三变位法动词的第三人称复数中，**-i-** 变为 **-u-**。这个 **-u-** 是第三人称复数早期形式的遗存，因此是构成现在时直陈式规则的一个例外。**请记住此例外**。
3. 在所有第三 i-词干变位法动词的第一人称单数中，改变后的现在时词干末尾的 **-i-** 不与词尾 **-ō** 和 **-or** 缩合。第一人称单数主动态即是**第一主要部分**。
4. 在所有第三 i-词干变位法动词的第三人称复数中，**-i-** 后跟 **-u-**。这个 **-u-** 是第三人称复数早期形式的遗存，因此是构成现在时直陈式规则的一个例外。**请记住此例外**。
5. 在第三和第三 i-词干变位法动词的第二人称单数被动态直陈式中，**-i-** 在词尾 **-ris** 和 **-re** 前变为 **-e-**。[^1] **请记住此例外**。
6. 在现在时直陈式中，第三 i-词干变位法动词仅在**第一人称单数**和**第三人称复数**上与第三变位法动词不同。
7. 在第四变位法动词的第一人称单数中，现在时词干末尾的 **-ī-** 在词尾 **-ō** 和 **-or** 前缩短（例如，\*audīō > **audiō**；\*audīor > **audior**）。第一人称单数主动态即是**第一主要部分**。
8. 在所有第四变位法动词的第三人称复数中，**-ī-** 缩短为 **-i-** 并后跟 **-u-**。这个 **-u-** 是第三人称复数早期形式的遗存，因此是构成现在时主动直陈式规则的一个例外。**请记住此例外**。
9. 在所有第四变位法动词的第三人称单数主动态中，词干元音 **-ī-** 根据长元音规则缩短。
10. 第三 i-词干变位法动词和第四变位法动词在第一人称单数、第三人称单数和第三人称复数上形式相同。

[^1]: 第三变位法的原始词干元音是 **-i-**，但这个 **-i-** 在现在时主动不定式的 **-re** 结尾前变成了 **-e-**。

### 第三、第三 i-词干和第四变位法的未完成时主动态与被动态直陈式

构成第三、第三 i-词干和第四变位法的未完成时主动态和被动态直陈式的步骤：

1. 取现在时词干
2. 如下所示改变词干元音：
	- 第三变位法：**-e- → -ē-**
	- 第三 i-词干变位法：**-e- → -iē-**
	- 第四变位法：**-ī- → -iē-**
3. 添加未完成时直陈式的中缀：**-bā-**
4. 添加 *主动态* 或 *被动态人称词尾*（第一人称单数用 **-m** 或 **-r**）

因此，例如 **regō, capiō** 和 **audiō** 的未完成时主动态直陈式变位如下：

| 改变后的现在时词干： | regē-         |                         | capiē-         |                           | audiē-         |                           |
| ---------- | ------------- | ----------------------- | -------------- | ------------------------- | -------------- | ------------------------- |
| 中缀：        | **-bā-**      |                         | **-bā-**       |                           | **-bā-**       |                           |
|            | *主动态*         | *被动态*                   | *主动态*          | *被动态*                     | *主动态*          | *被动态*                     |
| *单数*       |               |                         |                |                           |                |                           |
| 1          | **regēbam**   | **regēbar**             | **capiēbam**   | **capiēbar**              | **audiēbam**   | **audiēbar**              |
| 2          | **regēbās**   | **regēbāris/ regēbāre** | **capiēbās**   | **capiēbāris/ capiēbāre** | **audiēbās**   | **audiēbāris/ audiēbāre** |
| 3          | **regēbat**   | **regēbātur**           | **capiēbat**   | **capiēbātur**            | **audiēbat**   | **audiēbātur**            |
| *复数*       |               |                         |                |                           |                |                           |
| 1          | **regēbāmus** | **regēbāmur**           | **capiēbāmus** | **capiēbāmur**            | **audiēbāmus** | **audiēbāmur**            |
| 2          | **regēbātis** | **regēbāminī**          | **capiēbātis** | **capiēbāminī**           | **audiēbātis** | **audiēbāminī**           |
| 3          | **regēbant**  | **regēbantur**          | **capiēbant**  | **capiēbantur**           | **audiēbant**  | **audiēbantur**           |

**注意**

1. 第三变位法动词改变后的现在时词干（例如 **regē-**）与第二变位法动词的现在时词干（例如 **movē-**）相同。因此，第三变位法动词的未完成时直陈式变位类似于第二变位法动词。
2. 第三 i-词干和第四变位法动词的未完成时直陈式在中缀 **-bā-** 前都有 **-iē-**。因此，第三 i-词干变位法动词的未完成时直陈式变位类似于第四变位法动词。
3. 在上述三种变位法的第一人称单数主动态和被动态，第三人称单数主动态，以及第三人称复数主动态和被动态中，长元音根据长元音规则缩短。

### 第三、第三 i-词干和第四变位法的将来时主动态与被动态直陈式

构成第三、第三 i-词干和第四变位法的将来时主动态和被动态直陈式的步骤：

1. 取现在时词干
2. 如下所示改变词干元音：
	- 第三变位法：**-e- → -ē-**
	- 第三 i-词干变位法：**-e- → -iē-**
	- 第四变位法：**-ī- → -iē-**
3. 添加 *主动态* 或 *被动态人称词尾*（第一人称单数用 **-m** 或 **-r**）

因此，例如 **regō, capiō** 和 **audiō** 的将来时主动态直陈式变位如下：

| 改变后的现在时词干： | regē-       |                     | capiē-       |                       | audiē-       |                       |
| ---------- | ----------- | ------------------- | ------------ | --------------------- | ------------ | --------------------- |
|            | *主动态*       | *被动态*               | *主动态*        | *被动态*                 | *主动态*        | *被动态*                 |
| *单数*       |             |                     |              |                       |              |                       |
| 1          | **regam**   | **regar**           | **capiam**   | **capiar**            | **audiam**   | **audiar**            |
| 2          | **regēs**   | **regēris/ regēre** | **capiēs**   | **capiēris/ capiēre** | **audiēs**   | **audiēris/ audiēre** |
| 3          | **reget**   | **regētur**         | **capiet**   | **capiētur**          | **audiet**   | **audiētur**          |
| *复数*       |             |                     |              |                       |              |                       |
| 1          | **regēmus** | **regēmur**         | **capiēmus** | **capiēmur**          | **audiēmus** | **audiēmur**          |
| 2          | **regētis** | **regēminī**        | **capiētis** | **capiēminī**         | **audiētis** | **audiēminī**         |
| 3          | **regent**  | **regentur**        | **capient**  | **capientur**         | **audient**  | **audientur**         |

**注意**

1. 在第三变位法动词的第一人称单数中，词尾 **-m** 和 **-r** 前出现的是 **-ā-** 而非 **-ē-**。类似地，在第三 i-词干和第四变位法动词的第一人称单数中，词尾 **-m** 和 **-r** 前出现的是 **-iā-** 而非 **-iē-**。**请记住这些例外**。在所有情况下，根据长元音规则，**-ā-** 在 **-m** 和 **-r** 前缩短。在所有其他人称中，将来时的标志是 **-ē-**。
2. 用于标记第一和第二变位法动词将来时的中缀 **-bi-** 不用于第三、第三 i-词干和第四变位法。对于这些变位，将来时的标志是 **-ē-** 。
3. 在上述三种变位法的第一人称单数主动态和被动态，第三人称单数主动态，以及第三人称复数主动态和被动态中，长元音根据长元音规则缩短。

## §31. 所有动词的现在时被动态不定式

不定式被定义为具有时态（现在时、完成时或将来时）和语态（主动态或被动态）特性的动词性名词（§12）。每个动词的第二主要部分是现在时主动态不定式，通常译为"（去）\_\_\_\_"。要构成第一、第二和第四变位法动词的现在时被动态不定式，**将现在时主动态不定式的结尾 -e 改为 -ī**。例如：

| 现在时主动态不定式        | 现在时被动态不定式         |
| ---------------- | ----------------- |
| **vocāre** (去叫)  | **vocārī** (去被叫)  |
| **movēre** (去移动) | **movērī** (去被移动) |
| **audīre** (去听)  | **audīrī** (去被听到) |

要构成第三和第三 i-词干变位法动词的现在时被动态不定式，**去掉现在时主动态不定式的结尾 -ere 并添加 -ī**。[^2] 例如：

| 现在时主动态不定式        | 现在时被动态不定式       |
| ---------------- | --------------- |
| **regere** (去统治) | **regī** (去被统治) |
| **capere** (去捕获) | **capī** (去被捕获) |
[^2]: **faciō** 的现在时被动态不定式由另一个动词提供，参见 §126 。

## §32. 所有动词的现在时主动态与被动态命令式

命令式用于发出直接命令（见§5）。下面每个斜体动词在拉丁语中都会以命令式动词呈现：

- *吃* 你的蔬菜！
- *给* 我一把剑。
- *听着*，朋友们。

像这样的命令要么针对"你"（单数），要么针对"你们"（复数）。虽然命令是由说话人发出的，但是执行命令所含动作的主体是“你/你们”，所以命令式的主语是第二人称，只不过这些第二人称主语在拉丁语中很少表达出来。因为使用命令式时，有时需要直呼被命令者，所以命令式常常（但并非总是）与被命令者的呼格形式一起出现。例如，在上面的第三个句子中，"朋友们"就是呼格复数。

构成所有四种变位法的现在时主动态命令式：

1. （单数）取现在时词干，不作任何改动
2. （复数）取现在时词干，并加上 **-te**

| 现在时词干 | 现在时主动态命令式单数 |        | 现在时主动态命令式复数 |               |
| ------------ | ------------------------------- | ------ | ----------------------------- | ------------- |
| **vocā-**    | **vocā**                        | 召唤   | **vocāte**                    | 召唤（复）    |
| **movē-**    | **movē**                        | 移动   | **movēte**                    | 移动（复）    |
| **rege-**    | **rege**                        | 统治   | **regite**                    | 统治（复）    |
| **cape-**    | **cape**                        | 拿取   | **capite**                    | 夺取（复）    |
| **audī-**    | **audī**                        | 听     | **audīte**                    | 听（复）      |

**注意**

1. 第三变位法和第三-i-词干变位法的动词，在现在时主动态命令式复数中，词干元音 **-e-** 在词尾 **-te** 前变为 **-i-**。试比较此词干元音变化与同类变位法动词在现在时主/被动态直陈式中的变化（例如，**rege-** > **regi-**）。
2. **dō** 的现在时主动态命令式单数是 **dā**。虽然词干有短 **-a-**，但命令式单数形式（**dā**）中的 **-a-** 通过与其他第一变位法动词类比而加长了。
3. **eō** 的命令式的构成是规则的：**ī**（单数）和 **īte**（复数）。[^3]
4. 现在时命令式之所以如此称呼，是因为它们由现在时词干构成，但命令式着眼于将来，在时间上是将来。有些动词有替代的命令形式，称为将来时命令式。这些形式在词汇注释和阅读材料中会有标识。

[^3]: 不规则动词 **possum** 没有命令形式。**sum** 的命令形式是 **es**（单数）和 **este**（复数）。除了在 **sum** 的复合词中，这两种形式都很罕见。

四个第三变位法动词（**dīcō, dūcō, faciō, ferō**[^4]）的单数现在时主动态命令式有不规则形式。记住这些不规则形式。

| 现在时主动态<br>命令式单数 |       | 现在时主动态<br>命令式复数 |             |
| ----------------------------------- | ----- | --------------------------------- | ----------- |
| **dīc**                             | 说    | **dīcite**                            | 说（复）    |
| **dūc**                             | 引导  | **dūcite**                            | 引导（复）  |
| **fac**                             | 做    | **facite**                            | 做（复）    |
| **fer**                             | 携带  | **ferte**                             | 携带（复）  |

**注意**

1. 这些命令式的单数形式缺少词干元音。
2. **Dicō, dūcō** 和 **faciō** 的复数命令式形式是规则的。**ferō** 的命令式复数也是不规则的，同样缺少词干元音。

[^4]: 动词 **ferō, ferre, tulī, lātus**，"带来"，"携带"，"搬运"，"忍受"，是一个第三变位法动词，在现在时系统中具有某些不规则形式，这些形式在§43中呈现。

构成所有四种变位法的现在时被动态命令式：

1. （单数）取现在时词干，并加上 **-re**
2. （复数）取现在时词干，并加上 **-minī**

| 现在时词干     | 现在时被动态命令式单数 |     | 现在时被动态命令式复数  |        |
| --------- | ----------- | --- | ------------ | ------ |
| **vocā-** | **vocāre**  | 被召唤 | **vocāminī** | 被召唤（复） |
| **movē-** | **movēre**  | 被移动 | **movēminī** | 被移动（复） |
| **rege-** | **regere**  | 被统治 | **regiminī** | 被统治（复） |
| **cape-** | **capere**  | 被拿取 | **capiminī** | 被夺取（复） |
| **audī-** | **audīre**  | 被听见 | **audīminī** | 被听见（复） |

**注意**

1. 在第三变位法和第三-i-词干变位法动词的现在时被动态命令式复数中，词干元音 **-e-** 在词尾 **-minī** 前变为 **-i-**。
2. 现在时被动态命令式的单复数，与现在时被动态直陈式的第二人称单复数在形式上相同。此外，所有动词的现在时被动态命令式单数在形式上与现在时主动态不定式相同。例如：
    - **vocāminī**
        - 被召唤（复）（命令式）
        - 你们正在被召唤（直陈式）
    - **vocāre**
        - 被召唤（命令式）
        - 你正在被召唤（直陈式）
        - 去召唤（不定式）

    语境通常能表明某个特定句子中出现的是哪种形式。

**Dīcō** 和 **dūcō** 的现在时被动态命令式是规则的。**ferō** 的现在时被动态命令式单数是 **ferre**（被携带）。记住这个不规则形式。复数形式是规则的（**feriminī**，被携带[复]）。**Faciō** 没有被动态命令式。

**agō, agere, ēgī, āctus**，"驱动"，"做"的现在时主动态命令式 **age** 和 **agite**，在口语拉丁语中常用来加强其他命令。它们可以翻译为"来吧！"例如：

- ***Age*, dōnā puellīs dōna!** *来吧*，把礼物给女孩们！
- ***Agite*, ō virī, pugnāte!** *来吧*，哦，男人们，战斗吧！

## §34. 部分属格 

当一个属格名词表示*整体*，而另一个名词是其中的*一部分*时，它被称为**部分属格**（partitive genitive）。[^5] 例如： 

- **multī *incolārum* nōn labōrābunt.**   
很多人 *居民们的*<sub>部分属格</sub> 不 工作<sub>3复.将</sub> 。  
*居民*中的很多人将不工作。 

- **Nihil *odiī* habeō.**  
无 *仇恨的*<sub>部分属格</sub> 有<sub>1单.现</sub> 。  
我拥有仇恨中的"无"。 / 我没有任何*仇恨*（直接宾语）。/ 我毫无*仇恨*。 

每个斜体词（**incolārum, odiī**）的句法是**部分属格**。 

[^5]: 部分属格也被称为分割整体的属格（Genitive of the Divided Whole）。

## §35. 主语属格

当一个属格名词表达了*执行另一个名词所隐含的动词动作*的人或事物时，它被称为**主语属格**（Subjective Genitive）。例如： 

- **Magnum erat odium *malī* in bonos.**  
大的 是 仇恨 *坏人的*<sub>主语属格</sub> 对 好人的。  
*那个坏人*对好人的仇恨是巨大的。 

**注意**

- 在这个句子中，斜体词（**malī**）的句法是**主语属格**，因为那个坏人*感受到*或*执行了*名词 **odium** 所隐含的仇恨动作：那个坏人（主语）*仇恨*好人。

## §36. 宾语属格

当一个属格名词表达了*接受另一个名词所隐含的动词动作*的人或事物时，它被称为**宾语属格**（Objective Genitive）。例如： 

- **Propter odium *dominōrum* servī nōn labōrant.**  
由于 仇恨 *主人们的*<sub>宾语属格</sub> 奴隶们 不 工作<sub>3复.现</sub> 。  
由于（他们）对 *（他们的）主人*的仇恨，奴隶们不工作。 

**注意**

1. 在这个句子中，斜体词（**dominōrum**）的句法是**宾语属格**，因为主人 *接受* 或 *本身就是* 名词 **odium** 所隐含的仇恨动作的*对象*：奴隶们*仇恨*他们的主人（直接宾语）。 
2. 宾语属格在翻译时，可以在其前面添加“对”字使得动作的对象更明确。

除了依赖于其他名词外，宾语属格也可以与某些形容词和动词一起出现。例如： 

- **Vir *aurī cupidus* poenās dabit.** (**cupidus, -a, -um** 渴望的)  
人 *金子的<sub>宾语属格</sub> 渴望的* 受到惩罚<sub>3单.将</sub> 。  
一个 *对金子渴望的* 人将受到惩罚。 / 一个 *渴望金子的* 人将受到惩罚。

在这个句子中，宾语属格（**aurī**）依附于形容词 **cupidus**。 

主语属格和宾语属格可以同时出现，可以依靠词序区分两者。例如： 

- **Magnum erat *malī* odium *bonōrum*.**  
大的 是 *坏人的*<sub>主语属格</sub> 仇恨 *好人们的*<sub>宾语属格</sub> 。  
*那个坏人* *对好人* 的仇恨是巨大的。 

主语属格通常前置，而宾语属格通常后置于它们所共同依赖的名词。然而，这个句子也有可能意为"好人们（主语属格）对那个坏人（宾语属格）的仇恨是巨大的。" 上下文通常能清楚地表明一个特定的属格是主语属格还是宾语属格。

## §37. 方面夺格

当一个不带介词的夺格名词被用来限制或进一步明确一个形容词或动词的含义时，它被称为**方面夺格**（Ablative of Respect）。例如： 

- **Bonus *cōnsiliō* erat Gracchus.**  
好的 *判断力*<sub>方面夺格</sub> 是 格拉古。  
格拉古 *在判断力方面* 是很好的。/ 格拉古判断力强。 

- **Meā *sententiā* imperium habēre dēbēs.** (**meus, -a, -um** 我的) (**sententia, sententiae** *f.* 意见)

## §38. 人称代词

代词是用来代替名词的词，而**人称代词**（personal pronoun）代表说话者或写作者（我，我们）、听话者（你，你们[复数]）或被谈及的人或事物（他，她，它，他们/她们/它们）。

像名词一样，拉丁语中的人称代词也需要变格，其变格形式必须熟记。对于第一和第二人称代词，请**纵向熟记单数形式，纵向熟记复数形式**。

|      | 第一人称              |                | 第二人称               |                       |
| ---- | -------------------- | -------------- | -------------------- | --------------------- |
|      | *单数*               |                | *单数*               |                       |
| 主格 | **ego**              | 我             | **tū**               | 你                    |
| 属格 | **meī**              | 我的           | **tuī**              | 你的                  |
| 与格 | **mihi**             | 给/为了我       | **tibi**             | 给/为了你              |
| 宾格 | **mē**               | 我（直接宾语）    | **tē**               | 你（直接宾语）          |
| 夺格 | **mē**               | 从我（等）       | **tē**               | 从你（等）             |
|      | *复数*               |                | *复数*               |                       |
| 主格 | **nōs**              | 我们           | **vōs**              | 你们（复数）            |
| 属格 | **nostrum / nostrī** | 我们的         | **vestrum / vestrī** | 你们的（复数）          |
| 与格 | **nōbīs**            | 给/为了我们     | **vōbīs**            | 给/为了你们（复数）      |
| 宾格 | **nōs**              | 我们（直接宾语）  | **vōs**              | 你们（复数）（直接宾语）  |
| 夺格 | **nōbīs**            | 从我们（等）     | **vōbīs**            | 从你们（复数）（等）     |

**注意**

1. 人称代词没有呼格形式。
2. 由于限定动词的屈折词尾已经指明了主语（**-ō** = "我"，**-s** = "你"，等等），所以拉丁语句子中并不需要用到所有人称代词的主格形式。人称代词的主格形式最常用于加强语气。例如：
	- ***Ego* ambulō, nōn *tū*.** 是 *我* 在走路，不是 *你* 。
3. 在单数中，第一和第二人称代词的属格形式（**meī, tuī**）*仅*用作部分属格或宾语属格（§§34 和 36）。在复数中，属格的这些功能通过不同的词尾来区分：**nostrum, vestrum** = 部分属格，**nostrī, vestrī** = 宾语属格。例如：
	- **Habēsne odium *meī*?** 你对*我*怀有仇恨吗？（宾语）
	- **Multī *nostrum* rēgīnam amant**. *我们中的*许多人爱戴女王。（部分）
	- **Magnum erat odium *vestrī*.** 对*你们*的仇恨是巨大的。（宾语）
4. 当第一或第二人称代词用作伴随夺格时，介词 **cum** 会直接附着在代词后面。因此就会有 **mēcum**（和我一起），**nōbīscum**（和我们一起），**tēcum**（和你一起），和 **vōbīscum**（和你们[复数]一起）。

请**横向熟记第三人称代词的单数变格，再横向熟记其复数变格**（**is, ea, id, eius, eius, eius** ...）。

| 第三人称 | *单数*   |                  |             |                  |             |                  |
| ------------ | ------------ | ---------------- | ----------- | ---------------- | ----------- | ---------------- |
|              | 阳性           |                  | 阴性          |                  | 中性          |                  |
| 主格         | **is**       | 他               | **ea**      | 她              | **id**      | 它               |
| 属格         | **eius**     | 他的             | **eius**    | 她的            | **eius**    | 它的             |
| 与格         | **eī**       | 给/为了他         | **eī**      | 给/为了她        | **eī**      | 给/为了它         |
| 宾格         | **eum**      | 他（直接宾语）      | **eam**     | 她（直接宾语）     | **id**      | 它（直接宾语）      |
| 夺格         | **eō**       | 从他（等）        | **eā**      | 从她（等）        | **eō**      | 从它（等）         |
|              | ***复数*** |                  |             |                  |             |                  |
|              | 阳性           |                  | 阴性          |                  | 中性          |                  |
| 主格         | **eī/iī**    | 他们/她们/它们     | **eae**     | 她们/它们         | **ea**      | 它们             |
| 属格         | **eōrum**    | 他们/她们/它们的   | **eārum**   | 她们/它们的       | **eōrum**   | 它们/他们的       |
| 与格         | **eīs/iīs**  | 给/为了他们/她们/它们 | **eīs/iīs** | 给/为了她们/它们   | **eīs/iīs** | 给/为了它们/他们   |
| 宾格         | **eōs**      | 他们（直接宾语）    | **eās**     | 她们/它们（直接宾语） | **ea**      | 它们（直接宾语）    |
| 夺格         | **eīs/iīs**  | 从他们/她们/它们（等） | **eīs/iīs** | 从她们/它们（等）   | **eīs/iīs** | 从它们/他们（等）   |

**注意**

1. **Eius** 的发音类似于 \*eiius。第一个 **-i-** 与前面的元音结合形成双元音 **ei-**。第二个 **-i-** 是*辅音性*的，因此发音类似英语的 **y**。
2. **is, ea, id** 的所有形式都是双音节的，除了以下例外：**is, id**（单音节），**eōrum, eārum, eōrum**（三音节）。

3. 当 **is, ea, id** 的某种形式指代先前提到的人或事物时，它在*性*和*数*上要与其所指代的名词保持一致。例如：
	- **Liber pulcher puellae dabitur. *Eumne* habēs?**  
	那本漂亮的书将被送给那个女孩。你手上有*它*吗？（**eum** 指代 **liber**）

人称代词 **is, ea, id** 原本是一个指示形容词（这个，那个；这些，那些），而这个指示形容词用法一直保留着。**指示形容词**（demonstrative adjective, < **dēmōnstrō**，“指出”）通常位于它所修饰的名词之前，用来*指出*该名词。例如：

- **eum virum** 这个（*或* 那个）男人（直接宾语）（**eum** 是指示形容词，修饰 **virum**） 
- **ea perīcula** 这些（*或* 那些）危险（主语或直接宾语）（**ea** 是指示形容词，修饰 **perīcula**）

## §39. 物主形容词

属格形式的名词可以表示所有权或所属关系：**liber *puerī***（*那个男孩的*书）（§1）。然而，第一和第二人称代词的属格形式（**meī, nostrum/nostri, tuī, vestrum/vestri**）不用于表示所属关系（§38）。取而代之的是与每个人称代词相对应的**物主形容词**（possessive adjective）：

| 人称代词         |           | *对应的物主形容词*                     |                   |
| ---------------- | --------- | ------------------------------------ | ----------------- |
| **ego**          | 我        | **meus, -a, -um**                    | 我的              |
| **nōs**          | 我们      | **noster, nostra, nostrum**          | 我们的            |
| **tū**           | 你        | **tuus, -a, -um**                    | 你的              |
| **vōs**          | 你们（复数） | **vester, vestra, vestrum**          | 你们的（复数）       |

**注意**

1. **Meus, noster, tuus**, 和 **vester** 都属于第一第二变格法形容词。
2. 像所有形容词一样，物主形容词在性、数、格上与其修饰的名词保持一致。它们可以放在所修饰名词的前面或后面。例如：

	- **meās fīliās** 我的女儿们（直接宾语） 
	- **patriā nostrā** 从我们的祖国（等） 
	- **dominus vester** 你们（复数）的主人（主语）

3. 物主形容词可以作为名词使用。例如：
	- **meōrum** 我手下人的 *或* 我的东西
	- **tuōs** 你手下的人（直接宾语）

4. **meus** 的阳性单数呼格形式是 **mī**。请**熟记这个不规则的呼格形式**。

5. 如果句意在不使用物主形容词的情况下也能保持清晰，则物主形容词通常可以省略，但它们会被用来增加清晰度、强调或进行对比。

第三人称人称代词（**is, ea, id**）没有对应的物主形容词。相反，它的单数属格和复数属格形式被用作属有属格。例如：

- **librōs *eius***  
书<sub>直接宾语</sub> *他/她的*<sub>单数属格</sub>  
*他的/她的*书（直接宾语）

- **rēgīna *eōrum***  
女王<sub>主语</sub> *他们的*<sub>阳性复数属格</sub>  
*他们的*女王（主语）

| 所属关系总结 |                                  |                            |                                                                                         |
| --------------------- | -------------------------------- | -------------------------- | --------------------------------------------------------------------------------------- |
| 第一人称              | **meus fīlius<br>noster fīlius** | 我的儿子<br>我们的儿子       | **meus** 和 **noster** 是修饰 **fīlius** 的物主形容词                  |
| 第二人称              | **tuus fīlius<br>vester fīlius** | 你的儿子<br>你们（复数）的儿子 | **tuus** 和 **vester** 是修饰 **fīlius** 的物主形容词                  |
| 第三人称              | **fīlius eius<br>fīlius eōrum**  | 他的/她的儿子<br>他们的儿子   | **eius** 和 **eōrum** 是表达所属关系的属格人称代词 |
