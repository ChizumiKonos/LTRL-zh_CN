## 词汇注释

➤ **Athēnae, Athēnārum** *f. pl.* 仅以复数形式出现。（在英语中，Athens 词尾的 “s” 也表明该名称在形式上是复数。）

➤ 在拉丁语中，抽象名词的复数常表达具体的含义。因此，**amor, amōris** *m.* 的复数形式不再指单纯的、抽象的“爱”，而是指各种具体的“爱情”“感情”“恋爱关系”或“所爱对象”。当首字母大写为 **Amor** 时，则指爱神丘比特。

➤ **carmen, carminis** *n.* 由动词 **canō** 的词干加后缀 **-men** 构成。因此，**carmen** 的基本含义是“被歌唱或被吟诵之物”。它可以指赞美诗、仪式用语或咒语。由于古代诗歌常以歌唱形式呈现且总是出声朗诵，因此 **carmen** 可以指一首诗、一部戏剧或戏剧的一部分，无论它实际上是否被唱出来。它也可以抽象地指“诗歌”或“歌曲”。

➤ **Carthāgō, Carthāginis** *f.* （常拼写为带 **K** 的形式）是北非的一座城市，也是迦太基或腓尼基帝国的首都。在罗马扩张之前，迦太基帝国曾是西地中海地区最强大的国家。公元前3世纪以及公元前2世纪中期，罗马与迦太基之间爆发了战争。这些战争被称为布匿战争（Punic, < **Pūnicus, -a, -um**，腓尼基的，迦太基的）。最后一次布匿战争以迦太基的毁灭告终。其传说中的建立者和女王是狄多，在《埃涅阿斯纪》中，埃涅阿斯曾与她相遇。

➤ **cīvis, cīvis, -ium** *m.* 或 *f.* 指的是政治实体中的“公民”，与外国人、非公民或奴隶相对。在政治演说中，它也可指“同胞”或“同乡”。

➤ **homō, hominis** *m.* 的基本含义是“人类”，即有别于非人类的存在（如神灵、动物）。**homō** 比 **vir** 更中性，因为 **vir** 总是明确指男性，并且可能带有"有荣誉感或原则的人"这一含义。**homō** 的复数形式常用来泛指"人们"，与 **populus** 相对，后者指特定的"民族"或"民众"。

- **Hominēs multa impia dīcunt.** 人们说许多不敬的话。

➤ **hostis, hostis, -ium** *m.* 指的是一个国家的“公敌”，与 **inimīcus**（“私敌”）相对。

➤ **iūs, iūris** *n.* 表达的是“法律”或“权利”的抽象概念，而非某项具体的法律，对于具体的法律，拉丁语用 **lēx** 来表示。它也可以指“公民的权利”意义上的“权利”。此外，**iūs** 还可以表示“判决”或“法庭”（即进行判决的场所）。

➤ **mare, maris, \*-ium** *n.* 的属格复数词尾前有星号，是因为在现存的拉丁文学作品中并未出现 \*marium 这种形式。虽然出现了属格形式 **marum**，但 **mare** 的其他所有形式都明显含有第三变格法 i-词干名词的特征。

➤ **mēns, mentis, -ium** *f.* 既可指作为智力活动中心的“心智”，也可指由这种智力活动产生的“意图”或“目的”，还可表示“心态”或“态度”。

➤ **moenia, moenium** *n. pl.* 指的是环绕城市用于防御的城墙。

➤ 短语 **patrēs cōnscrīptī**，最常出现在呼格中，意为“（已被）登记在册的父老们”（也就是被纳入元老院成员名单的人）（< **cōnscrībō [con- + scrībō], cōnscrībere, cōnscrīpsī, cōnscriptus**，登记，注册）。这是对罗马元老院全体成员的常见称呼。该短语偶尔也出现在其他格中。不带分词 **cōnscrīptī** 的复数 **patrēs** 也可以用来表示“元老们”。

➤ **rūs, rūris** *n.* 指的是与城市相对的“乡村”，通常也以复数形式出现来表示这一含义。它的方位格形式是 **rūrī**。

➤ **servitūs, servitūtis** *f.* 是一个抽象名词，由名词 **servus** 的词干加后缀 **-tūs** 构成。

➤ **urbs** 的尾音节 **-bs** 发音如同 “taps” 中的 **ps**。**urbs** 通常特指罗马，而 **oppidum** 则指意大利境内较小的城镇。

➤ **vīs, —, -ium** *f.* 是一个不规则第三变格法名词。（关于 **vīs** 的完整变格见 §55。）在单数中，**vīs** 具有“力量”、“权力”或“暴力”的含义，而在复数中它的意思是“（身体或精神的）力气”。

- **Incolae oppidum vī cēpērunt.** 居民们用武力夺取了该镇。
- **Vīrēs nautārum superābantur.** 水手们的力量正被压倒。

➤ **līberō, līberāre, līberāvī, līberātus** 是一个及物动词，常伴有分离夺格（§58）。

- **Incolās perīculō līberāvimus.** 我们将居民们从危险中解救了出来。

➤ **careō, carēre, caruī, caritūrus** 是一个不及物动词。第四主要部分 **caritūrus**（即将缺乏）是将来主动分词。除了“缺乏”和“没有”的基本含义外，**careō** 还可以表示没有某种负面的东西，即“免于……”或“摆脱了……”。**careō** 需要接一个分离夺格（§58），这个夺格在翻译时可当成直接宾语处理。

- **Agricola amīcīs nōn caret.** 这个农夫不缺少朋友。/ 这个农夫并非没有朋友。
- **Fīlius rēgīnae cūrīs caruit.** 女王的儿子免于忧虑。

➤ **legō, legere, lēgī, lēctus** 可以表示“收集”（贝壳、骨头、战利品）或“选择”（领袖、法官）。通过“用眼睛收集并观察某物”的概念，它最终产生了“阅读”这一特定含义。

➤ **intellegō, intellegere, intelēxī, intelēctus** 是由前缀 **inter-** 加到 **legō** 上构成的复合动词。在复合词中 **inter-** 常意为“彻底地”。从"彻底地阅读或观察某物"这一概念，**intellegō** 演变出“理解”的意思。

➤ **vīvō, vīvere, vīxī, victūrus** 是一个不及物动词。第四主要部分 **victūrus**（即将活着）是将来主动分词。

➤ 除了表示"容易的"之外，**facilis, facile** 还可以用于形容容易加工的材料（易处理的）；形容行动自如的人或事物人或事物“”（敏捷的，灵活的）；以及形容容易被感动的神或人（有好感的、仁慈的、宽容的）。

➤ **difficilis, difficile** 是由前缀 **dis-** 加到 **facilis** 上构成的形容词。**difficilis** 展现了词干元音的规律性弱化。除了意为“困难的”，**difficilis** 还可用于形容难以被打动的人或动物（顽固的，僵化的，难驾驭的）。

➤ 当 **fēlīx, fēlicīs** 用来形容植物、树木、土地等时，意为“多产的”“富饶的”或“高产的”。在涉及预兆等内容时，它常常具有更广泛的含义，即“幸运的”或“吉祥的”。一个 **fēlix** 的人是“幸运的”，进而也可理解为“幸福的”。

➤ **autem** 是一个后置连词，用于连接两个句子或从句。大多数情况下，**autem** 用来引出与前文相反的观点（然而），但有时也仅表示另一个不同的、附加的想法（而且）。

- **Nihil scrībō. Multa autem legō.** 我什么也不写。然而，我阅读很多东西。
- **Antōnius bene dīcit. Bene autem scrībit.** 安东尼说话很好。而且，他写作也很好。

➤ 副词 **iūre** 原本是 **iūs** 的单数夺格。

➤ 与 **in** 类似，介词 **sub** 既可接宾格，也可接夺格。当它接宾格时，它表达要么是"向……下面"的运动，要么是从下"向上到"某处（城墙、山）的运动。当它接夺格时，它表示某人或某物处在其位置“下面”。它也可以表示“在…脚下”、“紧靠”或“靠近”（城墙，山脉）。

- **Militēs sub moenia mīsit.** 他将士兵们派到城墙下。
- **Erant militēs sub oppidō.** 有士兵在靠近城镇/在城镇脚下。

## §50. 完成时被动态系统

完成时、过去完成时和将来完成时被动态直陈式，都是由动词的第四主要部分与动词 **sum** 的各种形式结合来构成的。这种由多个词组合而成的动词形式被称为**复合动词形式**（compound verb form），完成时被动态系统的所有形式都属于复合动词形式。用于构成复合动词形式的成分必须要分开书写。

动词的第四主要部分，曾在 §7（第二章）中被提到过，通常是其完成时被动态分词，而分词是一种具有时态和语态属性的动词性形容词。对于及物动词的完成时被动态分词，尽管它在词汇条目中以词尾 **-us** 的形式出现，[^1] 但实际上，它也可以被写成带有全套形容词词尾的形式：**-us, -a, -um**。例如：**rēctus, -a, -um**。当这个形容词与 **sum** 的各种形式结合，构成完成时被动态系统中的复合形式时，它总是与动词的*主语保持一致*，因此始终*处于主格*。主语也决定了*性*和*数*。

[^1]: *不及物动词*的完成时被动分词，在词汇条目中会以中性词尾 **-um** 的形式给出。请记住，不及物动词一般不用于被动语态，但有时也会用于某些特殊情况，参见 §54。

## §51. 所有动词的完成时、过去完成时和将来完成时被动态直陈式

### 所有动词的完成时被动态直陈式

要构成所有动词的完成时被动态直陈式：

1.  取完成时被动态分词（第四主要部分）
2.  作为*一个独立的词*加上 **sum** 的现在时

因此，例如 **regō** 的完成时被动态直陈式变位如下：

| 完成时被动态分词 | rēctus, -a, -um          |                              |
| -------- | ------------------------ | ---------------------------- |
| **单数**   |                          |                              |
| 1        | **rēctus, -a, -um sum**  | 我过去被统治；我已经被统治了               |
| 2        | **rēctus, -a, -um es**   | 你过去被统治；你已经被统治了               |
| 3        | **rēctus, -a, -um est**  | 他/她/它过去被统治；他/她/它已经被统治了       |
| **复数**   |                          |                              |
| 1        | **rēctī, -ae, -a sumus** | 我们过去被统治；我们已经被统治了             |
| 2        | **rēctī, -ae, -a estis** | 你们过去被统治；你们已经被统治了             |
| 3        | **rēctī, -ae, -a sunt**  | 他们/她们/它们过去被统治；他们/她们/它们已经被统治了 |

**注意**

1. 完成时被动态直陈式的每种形式都是复合动词形式。构成它的两个词不能逐词翻译，而必须作为一个整体来处理，并根据完成时的两种含义（过去时间简单体或现在时间完成体）来翻译。在拉丁语的所有复合形式中，**sum** 通常出现在分词之后；不过有时也会调换顺序，且中间可能还会出现其他词语。例如，**rēctus est** 和 **est rēctus**，这两种表达都是正确的。

2.  如果主语是阳性，完成时被动态分词以 **-us**（单数）或 **-ī**（复数）结尾；如果主语是阴性，以 **-a**（单数）或 **-ae**（复数）结尾；如果主语是中性，以 **-um**（单数）或 **-a**（复数）结尾。例如：
    - **Rēctus est.** 他过去被统治。/ 他已经被统治了。
    - **Rēctae sumus.** 我们（阴性）过去被统治。/ 我们（阴性）已经被统治了。
    - **Oppida rēcta sunt.** 那些城镇过去被统治。/ 那些城镇已经被统治了。

### 所有动词的过去完成时被动态直陈式

要构成所有动词的过去完成时被动态直陈式：

1.  取完成时被动态分词（第四主要部分）
2.  作为*一个独立的词*加上 **sum** 的未完成过去时

因此，例如 **regō** 的过去完成时被动态直陈式变位如下：

| 完成时被动态分词 | rēctus, -a, -um           |                  |
| -------- | ------------------------- | ---------------- |
| **单数**   |                           |                  |
| 1        | **rēctus, -a, -um eram**  | 我那时已经被统治了        |
| 2        | **rēctus, -a, -um erās**  | 你那时已经被统治了        |
| 3        | **rēctus, -a, -um erat**  | 他/她/它那时已经被统治了    |
| **复数**   |                           |                  |
| 1        | **rēctī, -ae, -a erāmus** | 我们那时已经被统治了       |
| 2        | **rēctī, -ae, -a erātis** | 你们那时已经被统治了       |
| 3        | **rēctī, -ae, -a erant**  | 他们/她们/它们那时已经被统治了 |

**注意**

1. 过去完成时被动态直陈式的每种形式都是复合动词形式。构成它的两个词不能逐词翻译，而必须作为一个整体来处理，并根据过去完成时的含义（过去时间完成体）来翻译。一般来说，可以把过去完成时被动态直陈式按模板翻译成“那时已经被…了”，如果上下文中已经明确了过去时间点，则可以删掉“那时”。

2. 主语的性和数决定了完成时被动态分词的词尾。例如：
    - **Rēcta erat.** 她那时已经被统治了。
    - **Nautae rēctī erant.** 那些水手那时已经被统治了。

### 所有动词的将来完成时被动态直陈式

要构成所有动词的将来完成时被动态直陈式：

1.  取完成时被动态分词（第四主要部分）
2.  作为*一个独立的词*加上 **sum** 的将来时

因此，例如 **regō** 的将来完成时被动态直陈式变位如下：

| 完成时被动态分词 | rēctus, -a, -um           |                      |
| -------- | ------------------------- | -------------------- |
| **单数**   |                           |                      |
| 1        | **rēctus, -a, -um erō**   | 我到那时（就）已经被统治了        |
| 2        | **rēctus, -a, -um eris**  | 你到那时（就）已经被统治了        |
| 3        | **rēctus, -a, -um erit**  | 他/她/它到那时（就）已经被统治了    |
| **复数**   |                           |                      |
| 1        | **rēctī, -ae, -a erimus** | 我们到那时（就）已经被统治了       |
| 2        | **rēctī, -ae, -a eritis** | 你们到那时（就）已经被统治了       |
| 3        | **rēctī, -ae, -a erunt**  | 他们/她们/它们到那时（就）已经被统治了 |

**注意**

1. 将来完成时被动态直陈式的每种形式都是复合动词形式。构成它的两个词不能逐词翻译，而必须作为一个整体来处理，并根据将来完成时的含义（将来时间完成体）来翻译。

2. 主语的性和数决定了完成时被动态分词的词尾。例如：
    - **Oppidum rēctum erit.** 那个城镇到那时（就）已经被统治了。
    - **Rēctī erunt.** 他们到那时（就）已经被统治了。

## §52. 动词形态总览（四）：直陈式、不定式和命令式

在制作一个包含完成时被动态系统的动词形态总览时，除了动词、人称和数之外，还需要为主语选择一个性，因为完成时被动态系统的复合形式包含一个形容词（完成时被动态分词），该形容词总是与动词的主语保持一致。以下是以 **agō** 为例，第一人称单数阴性的动词形态总览范本：

主要部分：**agō, agere, ēgī, āctus**
人称、数和性：**第一人称单数阴性**

| *直陈式*  |            |                      |               |                        |
| 现在时    | **agō**    | 我驱赶                  | **agor**      | 我（正在）被驱赶               |

## §53. 复合动词形式中 sum 的省略；关于完成时被动态分词的注释

在完成时被动态系统的复合形式中，**sum** 要么经常被省略，要么就是一个 **sum** 用于多个分词。例如：

- **Postquam oppidum *captum* [est], miserī erant incolae.**  
  在…后 城镇 *攻占*<sub>3单.完.被</sub> ，悲惨的 是 居民 。  
  在城镇 *被攻占了* 之后，居民们很悲惨。

- **Poēta ā populō et *vīsus* et *audītus* est.**  
  诗人 被 人民 既 *看*<sub>3单.完.被</sub> 又 *听*<sub>3单.完.被</sub> 。  
  那位诗人被人民 *看到* 并且 *听到*。

**注意**

- 省略 **sum** 的复合动词形式，其时态一般是完成时，而被省略的 **sum**，其时态是现在时。在特殊语境下，复合动词形式的时态可以被假定为过去完成时或将来完成时。

完成时被动态分词（第四主要部分）不仅可以用于构成完成时、过去完成时和将来完成时被动态直陈式，还可以像任何其他第一第二变格法形容词一样使用。这时可把它翻译为“（已）被……的”。例如：

- **Servōs *captōs* vīdimus.**  
  奴隶<sub>直宾.复</sub> *已被捕获的*<sub>阳.复.宾</sub> 看<sub>1复.完</sub> 。  
  我们当时看到了那些 *被捕获的* 奴隶。

- **Fēminīs *interfectōrum* auxilium dabō.**  
 妻子<sub>与.复</sub> *已被杀死的*<sub>阳.复.属</sub> 帮助<sub>宾.单</sub> 给予<sub>1单.将</sub> 。  
  我将向那些 *被杀死的人的* 妻子们提供帮助。

**注意**

1.  第一个句子中的完成时被动分词与其所修饰的名词在性、数、格上保持一致。括号表示“已”这个字可以从翻译中省略。

2.  第二个句子中的完成时被动态分词被用作名词。某些完成时被动态分词的名词化用法非常普遍，以至于它们被视作中性的第二变格法名词。例如：**factum, factī** *n.* 事迹（[已]被做的事）；**dictum, dictī** *n.* 言语，格言（[已]被说的话）。

3.  当完成时被动态分词单独作为形容词出现时（即，*不在*复合动词形式中），它所描述的动作在主要动词的动作发生之时就已经完成了。例如，“我们看见”那些奴隶时，他们已经被“捕获”了。

## §54. 无人称被动态

不及物动词，其第四主要部分以 **-um** 结尾，通常没有任何被动语态的形式。然而，不及物动词有时会以*第三人称单数*被动态的形式出现，并且*没有明确的主语*。不及物动词的这种第三人称单数被动态（无论何种时态和语式）被称为**无人称被动态**。（impersonal passive，**无人称** “impersonal” 这个词意思是“没有人称主语”。）这种形式报告并强调了某个动作正在被做（将要被做、曾经被做等），但不指明是谁做的。例如：

- **Per viās errātur.**  
  沿着 街道 漫游<sub>3单.现.被</sub> 。  
  （直译）沿着街道，漫游（这件事）正在被做。  
  （意译）漫游正在沿着街道进行。

- **Bene pugnātum est in prōvinciā.**  
  好地 战斗<sub>3单.完.被</sub> 在行省中。  
  （直译）在行省中，良好地战斗（这件事）曾经被做。  
  （意译）行省中进行了一场漂亮的战斗。 / 行省中打了个好仗。

**注意**

1. 翻译无人称被动态的一般方法是把动词转化为名词性表达，即，把动词所表达的动作当成一件事情，然后再围绕这件事情本身进行叙述。

2. 作为无人称被动态的复合动词形式，其完成时被动态分词总是以中性主格单数 **-um** 结尾（例如，**pugnāt*um* est**）。分词的这个中性词尾表明该形式是无人称的。

3. 由于无人称被动态是一种限定动词形式，所以它可以被副词修饰，如第二个例句所示。然而，在翻译中，由于动词已经被转化为名词性表达，所以副词也需要转换成对应的形容词，这样才能修饰名词。

## §55. 名词词法：第三变格法

如果一个名词的单数属格词尾是 **-is**，那么它就属于第三变格法。

*关于性的说明*：第三变格法包含阳性和阴性名词，它们共用一套词尾；还包含中性名词，其词尾与阳/阴性名词略有不同。

**第三变格法的词尾**

| 阳性/阴性 |            |           | 中性    |            |           |
| ----- | ---------- | --------- | ----- | ---------- | --------- |
|       | 单数         | 复数        |       | 单数         | 复数        |
| 主格/呼格 | **--**[^2] | **-ēs**   | 主格/呼格 | **--**[^2] | **-a**    |
| 属格    | **-is**    | **-um**   | 属格    | **-is**    | **-um**   |
| 与格    | **-ī**     | **-ibus** | 与格    | **-ī**     | **-ibus** |
| 宾格    | **-em**    | **-ēs**   | 宾格    | **--**[^2] | **-a**    |
| 夺格    | **-e**     | **-ibus** | 夺格    | **-e**     | **-ibus** |

[^2]: 第三变格法的名词在主格单数上表现出很大的差异，没有单一词尾。请记住在单数主格词尾的位置留一个空。中性单数宾格总是与中性单数主格相同，也没有单一词尾。请记住在中性单数宾格词尾的位置留一个空。

彻底记住这两套词尾，先按单数列从上到下记忆，再按复数列从上到下记忆。准备好能够快速背诵这些词尾。

要变格一个第三变格法的阳性、阴性或中性名词，将适当的词尾添加到词干上。[^3] 例如：

|       | **mīles, mīlitis** *m.* 士兵 |               | **corpus, corporis** *n.* 身体 |                |
| ----- | -------------------------- | ------------- | ---------------------------- | -------------- |
| 词干    | mīlit-                     |               | corpor-                      |                |
|       | *单数*                       | *复数*          | *单数*                         | *复数*           |
| 主格/呼格 | mīles                      | mīlit**ēs**   | corpus                       | corpor**a**    |
| 属格    | mīlit**is**                | mīlit**um**   | corpor**is**                 | corpor**um**   |
| 与格    | mīlit**ī**                 | mīlit**ibus** | corpor**ī**                  | corpor**ibus** |
| 宾格    | mīlit**em**                | mīlit**ēs**   | corpus                       | corpor**a**    |
| 夺格    | mīlit**e**                 | mīlit**ibus** | corpor**e**                  | corpor**ibus** |

**注意**

1. 第三变格法阳性/阴性名词的某些词尾用于标记不止一个格：**-ēs** = 主格/呼格/宾格复数；**-ibus** = 与格/夺格复数。

2. 第三变格法中性名词的大多数词尾与第三变格法阳性/阴性名词的词尾相同。中性名词仅在主格/呼格/宾格复数中以 **-a** 结尾这一点上不同。中性单数主格仅由词汇条目提供，而单数宾格总是与单数主格相同。记住：在拉丁语中，所有中性词汇，主格宾格同形，无论单数还是复数。

[^3]: 记住：要找到任意名词的词干，就去掉其属格单数形式的词尾。

### 第三变格法 i 词干名词

有些第三变格法的名词，其属格复数词尾是 **-ium** 而不是 **-um**，并且还有其他一些略微不同的词尾。这些名词被称为**第三变格法 i 词干名词**。

**第三变格法 i 词干的词尾**

| 阳性/阴性 |            |                | 中性    |            |            |
| ----- | ---------- | -------------- | ----- | ---------- | ---------- |
|       | 单数         | 复数             |       | 单数         | 复数         |
| 主格/呼格 | **--**[^4] | **-ēs**        | 主格/呼格 | **--**[^4] | ***-ia***  |
| 属格    | **-is**    | ***-ium***     | 属格    | **-is**    | ***-ium*** |
| 与格    | **-ī**     | **-ibus**      | 与格    | **-ī**     | **-ibus**  |
| 宾格    | **-em**    | **-ēs/ *-īs*** | 宾格    | **--**[^4] | ***-ia***  |
| 夺格    | **-e**     | **-ibus**      | 夺格    | ***-ī***   | **-ibus**  |

[^4]: 第三变格法 i 词干名词在主格单数上表现出很大的差异，没有单一词尾。请记住在单数主格词尾的位置留一个空。中性单数宾格总是与中性单数主格相同，也没有单一词尾。请记住在中性单数宾格词尾的位置留一个空。

彻底记住这两套词尾，先按单数列从上到下记忆，再按复数列从上到下记忆。准备好能够快速背诵这些词尾。

要变格一个第三变格法 i 词干的阳性、阴性或中性名词，将适当的词尾添加到词干上。例如：

|       | **urbs, urbis, -ium** *f.* 城市 |                     | **animal, animālis, -ium** *n.* 动物 |                |
| ----- | ----------------------------- | ------------------- | ---------------------------------- | -------------- |
| 词干    | urb-                          |                     | animāl-                            |                |
|       | 单数                            | 复数                  | 单数                                 | 复数             |
| 主格/呼格 | urbs                          | urb**ēs**           | animal                             | animāl**ia**   |
| 属格    | urb**is**                     | urb**ium**          | animāl**is**                       | animāl**ium**  |
| 与格    | urb**ī**                      | urb**ibus**         | animāl**ī**                        | animāl**ibus** |
| 宾格    | urb**em**                     | urb**ēs**/urb**īs** | animal                             | animāl**ia**   |
| 夺格    | urb**e**                      | urb**ibus**         | animāl**ī**                        | animāl**ibus** |

**注意**

1.  本书中每个 i 词干名词的词汇条目，都在完整的属格单数词尾之后包含了属格复数词尾（**-ium**）。这个额外的词汇成分用于识别每个 i 词干名词，必须记住。

2.  阳性/阴性 i 词干名词的宾格复数有两种词尾（**-ēs/-īs**），含义上没有区别。阳性/阴性 i 词干名词与普通第三变格法名词的区别*仅在于属格复数和宾格复数*。

3.  中性 i 词干名词与所有其他第三变格法名词的区别在于，其夺格单数词尾是 **-ī**（而不是 **-e**）。中性 i 词干名词与普通中性第三变格法名词的区别在于，其主格/宾格复数词尾是 **-ia**（而不是 **-a**）。

4. 少数阳性/阴性 i 词干名词，其夺格单数有时会用 **-ī** 代替 **-e** 。这些名词会在词汇注释中标明。

在第三变格法的名词中，主格单数表现出各种各样的形式，并且主格单数和属格单数（词干的来源）在拼写上存在显著差异。此外，有些名词属于 i 词干组，而另一些则不属于。对于每个名词，所有这些重要信息都包含在词汇条目中。因此，对于每个第三变格法名词，记住完整的词汇条目至关重要。

由于形容词只需与其修饰的名词在性、数、格上保持一致，所以第一第二变格法形容词能够修饰第三变格法名词。例如：

- **mīlitēs bonī** 好的士兵们（阳性复数 主格/呼格）
- **corpus validum** 强壮的身体（中性单数 主格/呼格/宾格）
- **urbis pulchrae** 美丽城市的（阴性单数 属格）
- **multīs animālibus** 对于/来自/... 许多动物（中性复数 与格/夺格）

记住这个重要的不规则第三变格法名词的变格：

| ----- | ------- | --------------- |
| 主格/呼格 | **vīs** | **vīrēs**       |
| 属格    | **——**  | **vīrium**      |
| 与格    | **——**  | **vīribus**     |
| 宾格    | **vim** | **vīrēs/vīrīs** |
| 夺格    | **vī**  | **vīribus**     |

1. 属格单数和与格单数形式在现存拉丁文献中未出现。请记住在词汇条目的第二个元素和变格表中这两个形式的位置留空。

2. 在复数中，**vīs** 是一个第三变格法 i 词干名词，词干为 **vīr-**。原词干 **\*vīs-** 中的 **-s-** 通过 r 音化变成了 **-r-**（ 有关 r 音化的信息，参见 §10 注释 13）。

## §56. 第三变格法形容词

拉丁语中所有变格的形容词都借用名词变格法的词尾。总共只有两组形容词：第一第二变格法形容词，例如 **bonus, bona, bonum**（§17），以及**第三变格法形容词**，它们借用了第三变格法名词的词尾，并且总是使用所有 i 词干特征。

第三变格法形容词，根据其主格单数形式的数量，可分为以下三类：

1. 三形式。此类形容词有三种互不相同的单数主格形式，分别对应阳性、阴性、中性。
2. 二形式。此类形容词有两种单数主格形式，阳性和阴性共用一种形式，中性则使用另一种形式。
3. 一形式。此类形容词只有一种单数主格形式，阳性、阴性、中性共用此种形式。

这三类第三变格法形容词，它们的词汇条目写法示例如下：

- **ācer, ācris, ācre** 尖锐的，敏锐的；激烈的，凶猛的（三形式）
- **fortis, forte** 勇敢的；强壮的（二形式）
- **fēlīx, fēlīcis** 幸运的，好运的，幸福的（一形式）

**说明**

1. 对于三形式的第三变格法形容词，其词汇条目的元素组成从左到右分别是：阳性单数主格、阴性单数主格、中性单数主格。这与第一第二变格法形容词的词汇条目写法一致。
2. 对于二形式的第三变格法形容词，其词汇条目的元素组成从左到右分别是：阳性/阴性单数主格（通常以 **-is** 结尾）、中性单数主格（通常以 **-e** 结尾）。
3. 对于一形式的第三变格法形容词，其词汇条目的元素组成从左到右分别是：阳性/阴性/中性单数主格，阳性/阴性/中性*单数属格*。给出属格的目的是显示词干，因为此类形容词无法从主格形式直接求得词干。

要找到三形式和二形式的第三变格法形容词的词干，取*阴性单数主格*并去掉词尾 **-is**。要找到一形式的第三变格法形容词的词干，取*单数属格*并去掉词尾 **-is**。因此，对于上面的例子：

- **ācer, *ācr*is, ācre** 词干 = **ācr-**
- ***fort*is, forte** 词干 = **fort-**
- **fēlīx, *fēlīc*is** 词干 = **fēlīc-**

要变格一个第三变格法形容词，将这些词尾添加到词干上：

|           | 单数   |      |      | 复数       |             |           |
| --------- | ------ | ---- | ---- | ---------- | ----------- | --------- |
|           | 阳性   | 阴性 | 中性 | 阳性       | 阴性        | 中性      |
| 主格/呼格 | **—**  | **—**    | **—**    | **-ēs**     | **-ēs**     | **-ia**   |
| 属格      | **-is** | **-is** | **-is** | **-ium**    | **-ium**    | **-ium**  |
| 与格      | **-ī**  | **-ī**  | **-ī**  | **-ibus**   | **-ibus**   | **-ibus** |
| 宾格      | **-em** | **-em** | **—**    | **-ēs/-īs** | **-ēs/-īs** | **-ia**   |
| 夺格      | **-ī**  | **-ī**  | **-ī**  | **-ibus**   | **-ibus**   | **-ibus** |

**注意**

1.  第三变格法形容词在单数主格上表现出很大的差异，可能有三种词尾、两种词尾或一种词尾。记住每个第三变格法形容词的词汇条目。中性单数宾格总是与中性单数主格相同，也没有单一词尾。

2.  *所有第三变格法形容词都使用全部 i 词干特征。* 所有性的单数夺格词尾都是 **-ī**，这是借自中性 i 词干名词的词尾。复数词尾包含了借自第三变格法 i 词干名词的所有 i 词干特征：中性主格/呼格和宾格中的 **-ia**，属格中的 **-ium**，以及阳/阴性宾格中作为 **-ēs** 替代形式的 **-īs**。

例如，形容词 **fortis, forte** 变格如下：

| 词干: fort- | 单数       |            | 复数                 |              |
| ----------- | ---------- | ---------- | -------------------- | ------------ |
|             | M./F.      | N.         | M./F.                | N.           |
| 主格/呼格   | fortis     | forte      | fort**ēs**           | fort**ia**   |
| 属格        | fort**is** | fort**is** | fort**ium**          | fort**ium**  |
| 与格        | fort**ī**  | fort**ī**  | fort**ibus**         | fort**ibus** |
| 宾格        | fort**em** | fort**e**  | fort**ēs**/fort**īs** | fort**ia**   |
| 夺格        | fort**ī**  | fort**ī**  | fort**ibus**         | fort**ibus** |

由于形容词只需与其修饰的名词在性、数、格上保持一致，所以第一第二变格法形容词和第三变格法形容词都能够修饰所有变格法的名词。例如：

- **nautae ācrēs** 凶猛的水手们（阳性复数 主格/呼格）
- **fortia facta** 勇敢的事迹（中性复数 主格/呼格/宾格）
- **fēlīcīs virōs** 幸运的人们（阳性复数 宾格）
- **rēgis fortis** 一位勇敢国王的（阳性单数 属格）
- **mente ācrī** 凭借敏锐的心智（阴性单数 夺格）

## §57. 副词（二）

要从第三变格法形容词构成副词：

1.  取词干[^5]
2.  添加词尾 **-iter**

[^5]: 对于单数主格有三种或两种词尾的形容词，去掉阴性单数主格的 **-is**。对于单数主格只有一种词尾的形容词，去掉单数属格的 **-is**。

例如：

| 形容词                            | 词干       | 副词          | 翻译       |
| --------------------------------- | ---------- | ------------- | ---------- |
| **ācer, *ācr*is, ācre**         | **ācr-**   | **ācriter**   | 猛烈地     |
| ***fort*is, forte**             | **fort-**  | **fortiter**  | 勇敢地     |
| **fēlīx, *fēlīc*is**            | **fēlīc-** | **fēlīciter** | 幸运地     |

有些第三变格法形容词没有相应的副词（例如 **ingēns, ingentis**），有些则有不规则的副词形式。请记住以下常见的不规则副词：

| 形容词                     | 不规则副词    | 翻译             |
| -------------------------- | ------------- | ---------------- |
| **omnis, omne**            | **omnīnō**   | 完全地；全然     |
| **facilis, facile**        | **facile**   | 容易地           |
| **difficilis, difficile**  | **difficulter** | 困难地         |

## §58. 分离夺格

当一个夺格名词表达“某人/某物从该名词所表之人/物相分离”的概念时，这个名词的夺格就被称为**分离夺格**（Ablative of Separation）。[^6] 分离夺格一般不带介词出现，但有时也会使用介词 **ā/ab**、**ē/ex** 和 **dē**。例如：

- **Vir magnus populum *perīculō* līberābit.** (**līberō** [1-tr.] 使摆脱，释放，解救)  
人<sub>主.单</sub> 伟大的 人民<sub>直宾.单</sub> *危险*<sub>分离夺格</sub> 使摆脱<sub>3单.将</sub> 。  
那位伟人将使人民摆脱 *危险* 。

- **Bona est nostra vīta; nam *cūrīs* carēmus.** (**careō, carēre, caruī, caritūrus** (+ 夺格) 缺乏，没有，免于)  
美好的 是 我们的 生命；因为 *忧虑*<sub>分离夺格</sub> 没有<sub>1复.现</sub> 。  
我们的生命是美好的；因为我们没有*忧虑*。

- ***Odiō* lībera semper erat.**  
*憎恨*<sub>分离夺格</sub> 免于……的<sub>阴.单.主</sub> 总 是<sub>3单.未完</sub>。  
她那时总是免于*憎恨*。

每个斜体词 (**perīculō, cūrīs, odiō**) 的句法都是**分离夺格**。

[^6]: 关于分离作为夺格原始功能，请参见 §1。

## §59. 原因夺格

当一个夺格名词表达“该名词是某种性质或动作的*原因*或*理由*”时，这个名词的夺格就被称为**原因夺格**（Ablative of Cause）。原因夺格 *不带介词* ，通常可被翻译为“因为……”。例如：

- **Incolae *īrā* atque *odiō* bellum gerēbant.**  
居民<sub>主.复</sub> *愤怒*<sub>原因夺格</sub> 与 *憎恨*<sub>原因夺格</sub> 发动战争<sub>3复.未完</sub> 。  
居民们*因为愤怒*与*憎恨*发动战争。

每个斜体词 (**īrā, odiō**) 的句法功能是**原因夺格**。

**注意**

- 使用夺格来表达原因，意味着原因被理解为某一特定事件的*来源*，即事件由之而生的*起点*。因此，原因夺格反映了夺格最基本的*分离*功能。其他可与原因夺格等同的，表示理由或原因的表达方式还包括：**propter** + 宾格，**per** + 宾格，以及 **ē/ex** 或 **dē** + 夺格。

## §60. 起始地点夺格

当一个夺格名词被用来表达*运动的起始地点*时，它被称为**起始地点夺格**（Ablative of Place From Which）。通常会使用介词 **ā/ab**、**ē/ex** 或 **dē**。然而，*对于城市名、城镇名和小岛名，以及名词 **domus** 和 **rūs***，介词会被省略。例如：

- **Ab *Italiā* vēla dedimus.**  
  从 *意大利*<sub>起始地点夺格</sub> 起航<sub>1复.完</sub> 。  
  我们当时启程离开*意大利*。

- **Agēbāmur ex *patriā*.**  
  驱赶<sub>1复.未完.被</sub> 出 祖国<sub>起始地点夺格</sub> 。  
  我们当时正被驱逐出*祖国*。

- ***Rōmā* discēdam.**  
  *罗马*<sub>起始地点夺格</sub> 离开<sub>1单.将</sub>。  
  我将离开*罗马*。

每个斜体词 (**Italiā, patriā, Rōmā**) 的句法是**起始地点夺格**。起始地点夺格是分离夺格的一种特殊变体。

## §61. 所在地点夺格和方位格

### 所在地点夺格

当一个夺格名词表达“位置”的概念时，它被称为**所在地点夺格**。[^7] 通常会使用介词 **in**（较少使用其他某些介词，如 **sub** 或 **prō**）。[^8] 例如：

- **In *oppidō* erant multī nautae.** *在城镇里*有很多水手。

斜体词 (**oppidō**) 的句法是**所在地点夺格**。

### 方位格

拉丁语在其发展的早期阶段，有一个单独的名词格来表达位置。这个格被称为**方位格**，其词尾有时类似属格词尾，有时类似夺格词尾。大多数名词很早就失去了它们的方位格形式，位置开始由夺格表达。然而，*城市名、城镇名和小岛名，以及名词 **domus** 和 **rūs** 保留了它们的方位格形式*。记住以下常见的方位格形式：

| 名词                              | 方位格                             | 翻译             |
| --------------------------------- | ---------------------------------- | ---------------- |
| **domus, domī** *f.*            | **domī**                           | 在家里           |
| **rūs, rūris** *n.*             | **rūrī**                           | 在乡下           |
| **Rōma, Rōmae** *f.*            | **Rōmae**                          | 在罗马           |
| **Athēnae, Athēnārum** *f. pl.* | **Athēnīs**                        | 在雅典           |
| **Carthāgō, Carthāginis** *f.*  | **Carthāginī** 或 **Carthāgine**   | 在迦太基         |

[^7]: 关于位置作为夺格的一种功能，请参见 §1。

[^8]: 某些作者会省略掉某些词语的介词，此外某些常见短语也可能不带介词出现。例如：**terrā marīque**（在陆地和海上）。

**注意**

1.  对于保留了方位格形式的名词，其所在地点夺格通常不使用介词 **in** 。

2.  对于第一和第二变格法名词：
   a.  方位格单数词尾与属格单数词尾相同。
   b.  方位格复数词尾与夺格复数词尾相同。
   对于第三变格法名词，没有一致的规则。单数方位格词尾可以是 **-ī** 或 **-e**，或两者均可。

## §62. 目的地点宾格

当一个宾格名词被用来表达*运动朝向的目的地*时，它被称为**目的地点宾格**。通常会使用介词 **ad** 和 **in**（偶尔也会使用其他介词，如 **sub**）。然而，*对于城市名、城镇名和小岛名，以及名词 **domus** 和 **rūs***，介词会被省略。例如：

- **Fēmina ad *prōvinciam* mittitur.**  
  妇女 往 *行省*<sub>目的地点宾格</sub> 派遣<sub>3单.现.被</sub> 。  
  那位妇女正被派往*那个行省*。

- **Rōmānī *Athēnās* vēnērunt.**  
  罗马人 *雅典*<sub>目的地点宾格</sub> 来<sub>3复.完</sub> 。  
  罗马人来到了*雅典*。

每个斜体词 (**prōvinciam, Athēnās**) 的句法是**目的地点宾格**。

**地点表达总结**

|                                    | → “去往”某地               | x “在”某地                   | ← “来自”某地                     |
| ---------------------------------- | ---------------------- | ------------------------- | ---------------------------- |
| 大多数名词和代词                           | **ad/in/sub** + 目的地点宾格 | **in/sub** + 所在地点夺格       | **ē, ex**/**ā, ab** + 起始地点夺格 |
| 城市名、城镇名、小岛名，单词 **domus** 和 **rūs** | 无介词<br>目的地点宾格          | 方位格                       | 无介词<br>起始地点夺格                |
| *示例*                               |                        |                           |                              |
| **Rōma** 罗马                        | **Rōmam**              | **Rōmae**                 | **Rōmā**                     |
| **Athēnae** 雅典                     | **Athēnās**            | **Athēnīs**               | **Athēnīs**                  |
| **Carthāgō** 迦太基                   | **Carthāginem**        | **Carthāgine/Carthāginī** | **Carthāgine**               |
| **domus**                          | **domum**              | **domī**                  | **domō**                     |
| **rūs**                            | **rūs**                | **rūrī**                  | **rūre**                     |

    **昆图斯·恩尼乌斯**（Quintus Ennius，公元前239–169年）是古风时期拉丁文学最杰出的作家。他出生于意大利南部的布伦迪西乌姆（Brundisium）附近，母语为奥斯坎语。他被称为“三心之人”，因为他操奥斯坎语、拉丁语和希腊语。他的史诗《编年史》是第一部用长短短六步格——即希腊史诗格律——写成的拉丁史诗。全诗十八卷，叙述了罗马的全部历史，其中有数百残篇留存至今。在《编年史》中，恩尼乌斯颇为成功地将大量希腊文学风格的元素融入了自己的作品，而他这些开创性的努力影响了许多后世的拉丁诗人，包括维吉尔。[^9]

    《埃涅阿斯纪》是维吉尔最为知名的作品，也是拉丁文学中最负盛名的杰作。它是一部用长短短六步格写成的史诗，共分十二卷。全诗追溯了特洛伊英雄埃涅阿斯从故土沦陷地一路行至意大利的旅程与成长，他将在意大利以罗马之名建立起一座新的特洛伊。维吉尔很可能受麦凯纳斯与奥古斯都的鼓励，去写一部能与荷马的《伊利亚特》和《奥德赛》一较高下的罗马史诗。在这首诗中，维吉尔创造了一类新的罗马英雄，其最伟大之德性——**pietās**（对职责之虔敬）——是以高昂代价换来的。在重述关于罗马建城的传说时，维吉尔似乎在同一个文本中交织了对罗马帝国及其德性的正面与负面阐释：在讴歌罗马伟大之同时，《埃涅阿斯纪》也提请人们关注这份伟大的代价。

## §63. 拉丁语中的名字（二）

**Iūnō Vesta Minerva Cerēs Dīāna Venus Mars**
**Mercurius Iovis Neptūnus Volcānus Apollō** [^11]

尽管罗马人从希腊文学与文化中吸收了大量内容，但罗马宗教的许多方面，包括大多数神祇的名字，都源自意大利本土。许多意大利神祇因被等同于希腊神谱中的某位特定神祇，而失去了其原本的意义。例如，虽然在古典罗马时期马尔斯成了战神的名字，但该名字最初属于一位意大利的农业之神。

罗马人还实行将凡人奉为神的做法。在有史可考的时期中，这始于公元前44年尤利乌斯·凯撒被刺杀之后。[^12] 公元前43年，当天空中看到一颗彗星时，它被宣告为 **dīvus Iūlius**（“神圣的”或“被奉为神的尤利乌斯”）。（请学习这些形容词：**DĪVUS, -A, -UM** 奉为神的，神圣的；**DĪVĪNUS, -A, -UM** 属于神的，神圣的。）就连 **奥古斯都** 这一头衔——屋大维于公元前27年采用——也反映出罗马人在宗教事务上的独特关系。在屋大维将其作为尊号之前，形容词 **augustus, -a, -um**（“庄严的”，“受尊崇的”）只用于宗教器物、庙宇等类似之物，而从不用于人。
