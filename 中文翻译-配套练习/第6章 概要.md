# 第6章 概要

## 动词词法和句法

### 所有动词的完成时被动态直陈式系统

- **完成时被动态直陈式**  
取第4主要部分整体  
*以独立单词的形式* 添加 **sum** 的现在时主动态直陈式  
记得调整 *性* 和 *数*：例如，**rēctus, -a, -um est; rēctī, -ae, -a sunt**

- **过去完成时被动态直陈式**  
取第4主要部分整体  
*以独立单词的形式* 添加 **sum** 的未完成时主动态直陈式  
记得调整 *性* 和 *数*：例如，**rēctus, -a, -um erat; rēctī, -ae, -a erant**

- **将来完成时被动态直陈式**  
取第4主要部分整体  
*以独立单词的形式* 添加 **sum** 的将来时主动态直陈式  
记得调整 *性* 和 *数*：例如，**rēctus, -a, -um erit; rēctī, -ae, -a erunt**

### 无人称被动态

1. 不及物动词的*第三人称单数被动态*
2. 没有人称主语
3. 报告或强调该动词的动作正在进行，且不指明是谁执行该动作
4. 由复合动词形式构成的无人称被动态，其动词 *一般* 具有完成时被动分词，且该分词会以中性主格单数 **-um** 做词尾。

- **Per viās *errātur*.**  
沿着 街道<sub>宾.复</sub> 漫步<sub>3单.现.被</sub> 。  
（人们）沿着街道漫步。

- **Bene *pugnātum est* in prōvinciā.**  
好地 *战斗*<sub>3单.完.被</sub> 在行省里。  
在行省里打了一场漂亮的仗。

## 名词、形容词、副词词法

### 第三变格法的词尾

(属格单数词尾 **-is** 表明该名词属于第三变格法。)

| 阳性/阴性 | 单数        | 复数        | 中性  | 单数        | 复数        |
| ----- | --------- | --------- | --- | --------- | --------- |
| 主/呼   | **—[^1]** | **-ēs**   | 主/呼 | **—[^1]** | **-a**    |
| 属     | **-is**   | **-um**   | 属   | **-is**   | **-um**   |
| 与     | **-ī**    | **-ibus** | 与   | **-ī**    | **-ibus** |
| 宾     | **-em**   | **-ēs**   | 宾   | **—[^1]** | **-a**    |
| 夺     | **-e**    | **-ibus** | 夺   | **-e**    | **-ibus** |

### 第三 i-词干变格法的词尾

| 阳性/阴性 | 单数        | 复数            | 中性  | 单数        | 复数         |
| ----- | --------- | ------------- | --- | --------- | ---------- |
| 主/呼   | **—[^1]** | **-ēs**       | 主/呼 | **—[^1]** | ***-ia***  |
| 属     | **-is**   | ***-ium***    | 属   | **-is**   | ***-ium*** |
| 与     | **-ī**    | **-ibus**     | 与   | **-ī**    | **-ibus**  |
| 宾     | **-em**   | **-ēs/*-īs*** | 宾   | **—[^1]** | ***-ia***  |
| 夺     | **-e**    | **-ibus**     | 夺   | ***-ī***  | **-ibus**  |

[^1]: 由于第三变格法的名词在单数主格形式上变化多样，无法给出统一的词尾，因此单数主格处留空。中性单数宾格的形式始终与中性单数主格相同，故也留空。对于每个第三变格法名词，需将其单数主格形式作为词汇表条目的第一部分来记忆。

### 第三变格法不规则名词 *vīs*

**vīs, —, -ium** *f.* 力量，权力；暴力；*pl.* 力气

|     | 单数      | 复数              |
| --- | ------- | --------------- |
| 主/呼 | **vīs** | **vīrēs**       |
| 属   | **—**   | **vīrium**      |
| 与   | **—**   | **vīribus**     |
| 宾   | **vim** | **vīrēs/vīrīs** |
| 夺   | **vī**  | **vīribus**     |

### 第三变格法形容词词尾

|     | 单数      |         |         | 复数          |             |           |
| --- | ------- | ------- | ------- | ----------- | ----------- | --------- |
|     | 阳       | 阴       | 中       | 阳           | 阴           | 中         |
| 主/呼 | **—**   | **—**   | **—**   | **-ēs**     | **-ēs**     | **-ia**   |
| 属   | **-is** | **-is** | **-is** | **-ium**    | **-ium**    | **-ium**  |
| 与   | **-ī**  | **-ī**  | **-ī**  | **-ibus**   | **-ibus**   | **-ibus** |
| 宾   | **-em** | **-em** | **—**   | **-ēs/-īs** | **-ēs/-īs** | **-ia**   |
| 夺   | **-ī**  | **-ī**  | **-ī**  | **-ibus**   | **-ibus**   | **-ibus** |
1. 第三变格法形容词的词尾，与第三 i-词干变格法名词对应形式的词尾相同。
2. 夺格单数词尾总是 **-ī** 。
3. 第三变格法的形容词在单数主格中可能有*三种词尾*、*两种词尾*或*一种词尾*。例如：
	- **ācer** (阳), ***ācr*is** (阴), **acre** (中) 词干 = **ācr-**
	- ***fort*is** (阳/阴), **forte** (中) 词干 = **fort-**
	- **fēlīx** (阳/阴/中), ***fēlīc*is** 词干 = **fēlīc-**

### 从第三变格法形容词构成副词

1. 取词干 (e.g.，**fort-**)
2. 加上 **-iter** (e.g., **fortiter**)

**不规则副词**

- **difficulter** 困难地
- **facile** 容易地
- **omnīnō** 完全地

## 名词句法

| 概念                                                                                                                   | 示例                                                                                                 |
| -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **分离夺格**<br>1. 表示某人从某物或某事分离出来的概念<br>2. 有时使用介词 (**ā/ab**, **ē/ex**, 或 **dē**) ，但更多时候不带介词出现                            | **Populum *perīculō* līberāvit.**<br>他让人民摆脱了*危险*。                                                  |
| **原因夺格**<br>1. 表示某种性质或动作出现的原因或理由<br>2. 不使用介词                                                                         | **Incolae *īrā* pugnābant.**<br>当时居民们*因为愤怒*而在打架。                                                   |
| **起始地点夺格**<br>1. 表示运动的起始地点<br>2. 使用介词 (**ā/ab**, **ē/ex**, 或 **dē**) <br>3. 不使用介词的情况：城市名、城镇名、小岛名、**domus** 或 **rūs** | **Ab *Italiā* vēla dedimus.**<br>我们*从意大利*起航。<br>***Rōmā* discēdam.**<br>我将离开*罗马*。                  |
| **所在地点夺格**<br>1. 表示方位<br>2. 通常使用介词 (**in**; 有时 **sub, prō**)                                                         | **In *oppidō* erant multī nautae.**<br>*城镇里*有很多水手。                                                 |
| **方位格**<br>1. 表示方位的格<br>2. 用于城市名、城镇名、小岛名、**domus** 或 **rūs**                                                         | ***Rōmae* erant multī nautae.**<br>*罗马*有很多水手。                                                      |
| **目的地点宾格**<br>1. 表示运动的目的地点<br>2. 使用介词 (**ad, in**; 有时 **sub**, 其他) <br>3. 不使用介词的情况：城市名、城镇名、小岛名、**domus** 或 **rūs**   | **Fēminam ad *prōvinciam* mīsimus.**<br>我们送女人*到行省*。<br>**Fēminam *Rōmam* mīsimus.**<br>我们送女人*到罗马*。 |

## 动词直陈式词法总结

|     | 主动态人称词尾    |          | 被动态人称词尾        |           |
| --- | ---------- | -------- | -------------- | --------- |
|     | *单数*       | *复数*     | *单数*           | *复数*      |
| 1   | **-ō, -m** | **-mus** | **-or, -r**    | **-mur**  |
| 2   | **-s**     | **-tis** | **-ris / -re** | **-minī** |
| 3   | **-t**     | **-nt**  | **-tur**       | **-ntur** |

**长元音规则**：长元音在 **-m, -t, -nt, -r, -ntur** 前面会变成短元音。

**在 -ris, -re 前 -i- → -e-**

| 变位法    | 现在时主动态和被动态                | 词根变化          |                  |
| ------ | ------------------------- | ------------- | ---------------- |
| 1, 2   | 从第 2 主要部分获取词干（去掉 **-re**） | 无变化           | 加上适当的（主动或被动）人称词尾 |
| 3, 3-i | 同上                        | **-e- → -i-** | 同上               |
| 4      | 同上                        | 无变化           | 同上               |

例外：**voc*ō*, voc*or***; **move*ō*, move*or***; **reg*ō*, reg*or*, reg*unt*, reg*untur***; **cap*iunt*, cap*iuntur***; **audi*ō*, audi*or*, aud*iunt*, aud*iuntur***;

| 变位法  | 未完成时主动态和被动态               | 词根变化           | 中缀          |                  |
| ---- | ------------------------- | -------------- | ----------- | ---------------- |
| 1, 2 | 从第 2 主要部分获取词干（去掉 **-re**） | 无变化            | 加上 **-bā-** | 加上适当的（主动或被动）人称词尾 |
| 3    | 同上                        | **-e- → -ē-**  | 同上          | 同上               |
| 3-i  | 同上                        | **-e- → -iē-** | 同上          | 同上               |
| 4    | 同上                        | **-ī- → -iē-** | 同上          | 同上               |

| 变位法  | 将来时主动态和被动态                | 词根变化           | 中缀          |                  |
| ---- | ------------------------- | -------------- | ----------- | ---------------- |
| 1, 2 | 从第 2 主要部分获取词干（去掉 **-re**） | 无变化            | 加上 **-bi-** | 加上适当的（主动或被动）人称词尾 |
| 3    | 同上                        | **-e- → -ē-**  | （无）         | 同上               |
| 3-i  | 同上                        | **-e- → -iē-** | （无）         | 同上               |
| 4    | 同上                        | **-ī- → -iē-** | （无）         | 同上               |

例外：**voca*bō*, voca*bor*, voca*bunt*, voca*buntur***; **movē*bō*, movē*bor*, movē*bunt*, movē*buntur***; **reg*am*, reg*ar***; **cap*iam*, cap*iar***; **aud*iam*, aud*iar***;

|                                                                                                                            |                                                                                                                              |
| -------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **完成时主动态**<br>从第 3 主要部分获取词干（去掉 **-ī**）<br>根据性和数添加词尾 **-ī, -istī, -it, -imus, -istis, -ērunt/-ēre**（从左到右：1/2/3 单, 1/2/3 复.) | **完成时被动态**<br>取第4主要部分整体<br>*以独立单词的形式* 添加 **sum** 的*现在时主动态直陈式* （记得调整性和数：例如，**rēctus, -a, -um est; rēctī, -ae, -a sunt**）      |
