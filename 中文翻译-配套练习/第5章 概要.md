# 第5章 概要

## 所有动词的完成时主动态直陈式系统

| 完成时[^1]                  | 过去完成时[^2]                | 将来完成时[^3]                |
| ------------------------ | ------------------------ | ------------------------ |
| 从第 3 主要部分获取词干（去掉 **-ī**） | 从第 3 主要部分获取词干（去掉 **-ī**） | 从第 3 主要部分获取词干（去掉 **-ī**） |
|                          | 加上 **-erā-**             | 加上 **-eri-**             |
| 加上主动态人称词尾：               | 加上主动态人称词尾：               | 加上主动态人称词尾：               |
| *单数*                     | *单数*                     | *单数*                     |
| 1 **-ī**                 | 1 **-m**                 | 1 **-ō**[^4]             |
| 2 **-istī**              | 2 **-s**                 | 2 **-s**                 |
| 3 **-it**                | 3 **-t**                 | 3 **-t**                 |
| *复数*                     | *复数*                     | *复数*                     |
| 1 **-imus**              | 1 **-mus**               | 1 **-mus**               |
| 2 **-istis**             | 2 **-tis**               | 2 **-tis**               |
| 3 **-ērunt/-ēre**        | 3 **-nt**                | 3 **-nt**                |
**长元音规则**：长元音在 **-m, -t, -nt, -r, -ntur** 前面会变成短元音。

[^1]: 完成时既可以表示现在时间完成体 (e.g. "I have seen") 也可以表示过去时间一般体 (e.g. "I saw").
[^2]: 过去完成时表示过去时间完成体 (e.g. "I had seen").
[^3]: 将来完成时表示将来时间完成体 (e.g. "I shall have seen").
[^4]: 例外：**rēxerō** (而非 \***rēxeriō**)

**ferō, ferre, tulī, lātus** “带来，承受，携带；忍耐”

| 现在时直陈式     | 主动态          | 被动态                |
| ---------- | ------------ | ------------------ |
| *单数*       |              |                    |
| 1          | **ferō**     | **feror**          |
| 2          | ***fers***   | ***ferris/ferre*** |
| 3          | ***fert***   | ***fertur***       |
| *复数*       |              |                    |
| 1          | **ferimus**  | **ferimur**        |
| 2          | ***fertis*** | **feriminī**       |
| 3          | **ferunt**   | **feruntur**       |
| **现在时命令式** |              |                    |
| *单数*       | ***fer***    | ***ferre***        |
| *复数*       | ***ferte***  | **feriminī**       |
| **现在时不定式** |              |                    |
| *单数*       | ***ferre***  | ***ferrī***        |
| *复数*       | (无)          | (无)                |

## 条件句概要

| 条件句名称                    | 拉丁语中的动词                     | 英语中的动词[^5]                         |
| ------------------------ | --------------------------- | ---------------------------------- |
| **现在简单条件句**              | 条件从句和结论主句[^6]中都用直陈式现在时      | 无需特殊翻译                             |
| **过去简单条件句**              | 条件从句和结论主句中都用直陈式的任何过去时态      | 无需特殊翻译                             |
| **将来更大可能性条件句 (FMV)**     | 条件从句和结论主句中都用直陈式将来时          | 条件从句中用现在时（does），结论主句中用将来时（will do） |
| **强调式将来更大可能性条件句 (FMVE)** | 条件从句中用直陈式将来完成时，结论主句中用直陈式将来时 | 条件从句中用现在时（does），结论主句中用将来时（will do） |
[^5]: 译成英文时使用情态动词 "do"。
[^6]: **条件从句**指的是条件句的从句（或“if 分句”）。**结论主句**指的是条件句的主句。

**副词**
1. 取词干（去掉第一第二变格法形容词阴性单数主格词尾）
2. 加上 **-ē**

**不规则副词**
- **bene** 好地
- **male** 坏地，糟糕地
- **multum** 很多地，大量地
- **valdē** 强烈地
